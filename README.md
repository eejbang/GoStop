# 오후 한 판 — 2인 맞고

컴퓨터 다람이와 즐기는 한국어 맞고 게임입니다. 별도 패키지 설치 없이 실행됩니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 열고 실행하세요.

```sh
npm start
```

브라우저에서 **http://localhost:5173** 에 접속합니다. 서버는 이 컴퓨터에서만 접속하도록 설정되어 있습니다. 다른 포트는 `PORT` 환경 변수로 지정할 수 있습니다.

Windows에서 Node.js가 PATH에 없다면 `실행하기.bat`을 더블 클릭하세요. 기존 Codex Node.js 런타임도 자동으로 찾아 사용합니다.

## 플레이

- **첫 판 시작하기**를 누르고 손패를 누르거나 바닥으로 끌어 놓습니다. 같은 무늬 위에 내려치고, 더미에서 한 장을 뒤집은 뒤 먹은 패를 가져오는 동작을 보여 줍니다.
- 상단 소개와 하단 푸터 없이 게임판을 넓게 표시합니다. FHD 화면에서는 손패 112×168px, 바닥 패 96×144px로 크게 볼 수 있습니다.
- 바닥의 위아래 여백을 줄여 먹은 패는 FHD에서 최대 64×96px로 표시합니다. 추천 이유는 손패 위 안내 줄에서 확인합니다.
- 같은 월의 바닥 패가 **두 장일 때만** 팝업에서 칠 패를 고릅니다. 패 그림, 이름, **선택하기** 중 어디를 눌러도 선택됩니다. 팝업에는 내가 선택한 손패가 함께 보이고, 취소하면 손패를 다시 고를 수 있습니다. 뒤집은 패의 먹을 대상이 둘일 때도 팝업으로 선택합니다. **세 장이면 팝업 없이** 패를 내려치고, 네 장을 함께 먹는 시각 효과를 보여 줍니다. 뒤집은 패가 바닥 세 장을 먹을 때도 같은 효과를 표시합니다.
- 7점부터 고·스톱을 선택합니다. 고를 선택한 뒤 획득 점수가 늘면 다시 선택할 수 있습니다.
- **힌트 보기**를 켜면 매 차례 추천 손패와 먹을 바닥 패를 계속 표시합니다. 다시 누르면 꺼집니다. 설정은 다음 판과 새로고침 후에도 유지됩니다.
- 숫자 **1~9, 0**: 손패 내기 / **H**: 힌트 켜기·끄기 / **G**: 고 / **S**: 스톱
- 같은 월 세 장이 손에 있으면 양쪽 플레이어 모두 자동 흔들기가 적용됩니다. 바닥에 같은 월 한 장이 있으면 손패에 **폭탄 가능**이 표시됩니다. 해당 손패를 누르면 **폭탄 · 세 장 내기**와 **선택한 한 장만 내기** 중 고릅니다. 별도 폭탄 버튼도 사용할 수 있고, 이후 폭탄 뒤집기 두 번을 사용합니다. 같은 세 장에 흔들기와 폭탄 배율을 중복 적용하지 않습니다.
- 폭탄은 금빛 폭발, 뻑은 붉은 도장, 따닥은 두 번의 청록색 파동을 패가 모인 자리에서 보여 줍니다. 뻑은 바닥에 세 장이 겹친 더미와 `뻑 · 3장` 표시로 남습니다. 동작 줄이기 설정에서는 움직임 없이 결과 표시만 보여 줍니다.
- 설정에서 AI 난이도, 플레이 속도, 소리를 바꿉니다. 전적과 설정은 브라우저에 저장됩니다.

## 채택한 규칙

기본 48장, 손패 각 10장, 바닥 8장, 더미 20장. 기본 점수는 광·열끗·띠·피 및 고도리·홍단·청단·초단을 합산합니다. 9월 국진은 쌍피로 고정합니다. 한국 화투 표기대로 **11월은 오동, 12월은 비**입니다.

뻑, 자뻑, 쪽, 따닥, 판쓸이, 흔들기, 세 장 폭탄, 피 가져오기, 피박(상대 피 7장 이하), 광박, 멍따, 고박을 지원합니다. 고마다 1점을 더하고 3고부터 두 배씩 배율이 증가합니다. 나가리 다음 판은 2배, 연속 나가리는 최대 8배입니다. 손패 총통은 10점 즉시 승리, 바닥 총통은 다시 나눕니다. 3뻑은 7점 즉시 승리합니다. 마지막 손패는 뻑·쪽·판쓸이의 특수 보상에서 제외합니다. 첫뻑·연속뻑·첫따닥의 별도 정산과 보너스패는 사용하지 않습니다.

기본 규칙 참고: [한게임 공식 가이드](https://mgostop.hangame.com/guide/combine/02_01_rule.html), [족보](https://mgostop.hangame.com/guide/combine/02_03_rule.html), [특수 상황](https://mgostop.hangame.com/guide/combine/02_02_rule.html). 플랫폼별 차이가 있는 부분은 위 규칙을 따릅니다. 실제 화폐 없이 점수로만 진행합니다.

## 검증

```sh
npm test
```

게임 엔진은 DOM과 분리되어 있고, 시드 기반 무작위 대국에서 패 보존과 게임 종료를 검증합니다. 외부 라이브러리, 외부 폰트, 이미지 네트워크 요청 없이 동작합니다.

## 파일

- `index.html`, `styles.css`: 반응형 게임 화면
- `src/cards.js`, `assets/hwatu-reference.png`: 화투 48장 정의와 전통 화투 도안
- `src/table-motion.js`: 패 내려치기, 뒤집기, 먹은 패 가져오기 동작
- `src/game.js`: 게임 규칙, 점수 계산, AI
- `src/app.js`: 사용자 입력, 소리, 대화 상자, 브라우저 저장
- `server.mjs`: 의존성 없는 로컬 서버
- `tests/game.test.mjs`: 게임 엔진 회귀 검증
